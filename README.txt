MY ANDROID APP — STARTER PROJECT

This ZIP contains the source project for a simple Android app named "My App".
It is not an APK, so you cannot install this ZIP directly on your phone.

HOW TO BUILD AN APK:
1. On a computer, install Android Studio from https://developer.android.com/studio
2. Extract this ZIP.
3. In Android Studio, choose Open and select the extracted MyAndroidApp folder.
4. Allow Gradle sync to finish.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show a link to the generated APK.
7. Transfer the APK to your Android phone and open it to install.

NOTE:
This is a basic starter app. To build it, Android Studio needs internet access
to download the Android Gradle Plugin and Kotlin plugin. No Gradle wrapper is
included in this ZIP.

To customize the app, edit MainActivity.kt and change the app label in
app/src/main/AndroidManifest.xml.
